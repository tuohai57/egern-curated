# Native module restoration

Restores all 96 module entries from the user-supplied v12.5 configuration. Original 90 enabled / 6 disabled flags are retained; one ordered protection module and one reviewed advertising delta module are added. Personal configuration, subscriptions, proxy credentials and CA are excluded from this repository.

Original module and JavaScript bytes, authors and provenance are retained in `originals/`, `scripts/` and `manifest.json`. Original script URLs remain in the modules. Required Egern compatibility corrections include body and binary flags, broken jq quoting, missing defaults, invalid rejection placeholders and original BiliBili gRPC response bytes and FMZ Meituan tiny-gif local responses. `url-path-ownership.json` documents limited, evidenced path exceptions that prevent known handlers from being preempted.

Run `python curated/tools/check_native_full.py` and `node curated/tools/test_native_full.cjs` from the repository root. Checks verify hashes, structure, jq compilation and synthetic behavior. They do not certify Egern 2.22.0 import, legacy script execution, CA trust, current App API contracts, privacy of system DNS fallback, or absence of every advertisement/countdown. Two scripts require function-scope runtime verification; one unavailable remote jq and one condition-lost logical rule are omitted. Full arbitrary-regex shadow proof is not claimed. See the manifest for all compatibility changes.

Reviewed: 2026-11-10. Upstream last-change timestamps have not been independently established for every asset; the review date is not an upstream update date.

The supplementary remote set now derives from the full literal-domain feeds of HaGeZi Multi PRO and QuixoticHeart. Ordinary App routing is not counted as blocking. Source hashes, exact counts and finite ownership exclusions are in `repository-supplement-audit.json`. HaGeZi's unmodified source and GPL-3.0 license accompany the derived set in `originals/`.

Run `python curated/tools/test_adblock_coverage.py` for independent ad/tracker targets, normal-function negatives and synthetic ownership checks. Its fixtures are not read by the rule generator. The public testing website is also never read by the rule generator. A page that treats every failed 1500ms HEAD request as blocked cannot distinguish deliberate blocking from DNS/TLS/server/time-out failure; its list also contains login APIs, mail redirects, feature configuration, consent controls and actual video players. A full page score is not a functional or security acceptance criterion.

App-path review is separate from the website: `app-path-fixtures.json` records 54 synthetic URL witnesses, 27 explicit transport/UA contexts and 21 unrelated-business-path negatives. New paths cite original module hashes and exact author regexes; this is not captured phone traffic. Run `python curated/tools/test_app_ad_paths.py`; optional `--profile` checks the actual private profile's MITM exclusions and DNS decisions without publishing that file.

`transport-ownership.json` preserves the original domain-scoped UDP/QUIC REJECT rules ahead of response-host routing allowances, while financial/necessary-service guards remain first. Protocol enums follow the official lowercase spelling. Four HTTPDNS UA patterns lost accidental literal quotes from the old conversion. Reviewed intersections select one response owner and prevent duplicate invocation of the same request script. Original JavaScript bytes remain unchanged. This does not add global UDP blocking or claim that every encrypted, pinned, cached, server-inserted or client-timed ad is removed.
